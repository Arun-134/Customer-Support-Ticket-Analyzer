# Customer-Support-Ticket-Analyzer
A Python project designed to analyze customer support tickets by cleaning text, extracting insights, and generating summary statistics.

# 🚀 Project Overview
Customer support teams manage numerous tickets daily. This analyzer helps identify:

Common issues

Customer sentiment

Support quality

Areas for improvement

The project uses Python to store, clean, analyze, and summarize ticket data.

# 🛠 Features
**Data Loading & Organization:**

Preloaded dictionary of 10 tickets

Auto-increment ticket numbers for new entries

Priority validation (High / Medium / Low)

**Text Cleaning:**

Remove punctuation

Normalize spaces

Convert to lowercase

Replace slang/shorthand (e.g., "ok" → "okay")

**Keyword Insights:**

Function to count tickets containing specific words

Case-insensitive search for terms like poor, good, slow, excellent

**Summary & Analytics:**

Priority distribution (High, Medium, Low)

Longest issue description (ticket number, customer, word count)

Unique word extraction (sorted list + count)

# 📜 Summary
This project highlights Python for data analytics with a focus on text cleaning, keyword-based insights, and structured reporting. It demonstrates beginner-to-intermediate proficiency in handling real-world support ticket data.
